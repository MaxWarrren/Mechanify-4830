Mechanify

An AI-powered mechanic shop management platform for tracking customers, vehicles, repair jobs, and answering technical questions from uploaded PDF manuals.

Angular 21 Node.js + Express MongoDB Atlas Google Gemini AI
Overview

What Problem Does It Solve?

🔧

Shop Operations

Mechanics need a single place to manage customers, track vehicles, and monitor repair job status — without paper or disconnected spreadsheets.

🤖

AI Knowledge Access

Technicians can upload vehicle PDFs and ask the AI assistant specific questions, getting answers with page-level citations from the actual manual.

📊

Customer Pipeline

A CRM-style view tracks customers from Lead → Active → Returning — showing open jobs, lifetime revenue, and last service date at a glance.

💬

Persistent Chat Sessions

Chat conversations are saved to MongoDB. Users can switch between sessions and the AI always has the right context without bloating its window.

Features

Core Shop Management

👥

Customer CRM

Pipeline status, search + filter, lifetime revenue, vehicle count, last service date. Inline status updates.

🚗

Vehicles

Full CRUD — make, model, year, VIN, mileage. Owner lookup, open job count, last service date. Detail view with full job history.

🛠️

Repair Jobs

Status tracking (Pending / In-Progress / Completed), estimated vs actual cost. Metric tiles for counts per status.

Features

AI Chat + Knowledge Base

📄

PDF Knowledge Base

Upload vehicle manuals. Each page is chunked, embedded with Voyage AI, and stored as vectors in MongoDB Atlas for semantic search.

🔍

RAG Pipeline

User selects a manual before chatting. Top relevant chunks are retrieved via vector search and injected into the Gemini prompt as context.

📖

Page Citations

The AI references exact page numbers from the manual in its answers. Responses render full markdown formatting.

💾

Multi-Session Memory

Conversations persist in MongoDB. Each session stores its full message history. LLM receives only the last 10 messages to keep context lean.

Engineering

Key Technical Challenges

  • Angular 21 Zoneless Default Angular 21 defaults to zoneless change detection — HTTP subscribe callbacks weren't triggering re-renders. Fixed with one line: provideZoneChangeDetection() in app.config.ts.
  • Embedding Rate Limits → Voyage AI Gemini Embedding 2 hit TPM limits during development. Switched to Voyage AI (voyage-4-lite, 1024-dim, 200M free tokens) with a custom REST integration.
  • pdf-parse v2 API Break The library changed from a function export to a class in v2. Required rewriting the upload controller to use new PDFParse() and page-level text extraction.
  • SSE Streaming + Session Persistence Streaming Gemini responses via SSE while buffering the full reply to persist to MongoDB at stream end — without blocking the client.
